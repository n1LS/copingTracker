# Dictionary

The *randomize project name* feature uses a small list of adjectives and nouns, baked into the application. To allow users to use project names with their preferred flavor or language, users can put the two files `adjectives.txt` and `nouns.txt` into the copingTracker folder on the SD card.

# File format

Both files are plain text listings of words. Words in `adjectives.txt` can have a maximum of 7 letters per word and 8 letters per word in `nouns.txt`.

Each word is separated by a line-break (character `\10`).
